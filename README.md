# AstroShield — constelación inteligente sobre Veguitto

Algoritmo evolutivo que diseña una constelación de **8 satélites** para observar seis regiones del planeta ficticio **Veguitto**, respetando zonas de escombros espaciales y posiciones ocupadas por otros objetos.

Práctica de Fundamentos de Inteligencia Artificial (UT Cancún).
